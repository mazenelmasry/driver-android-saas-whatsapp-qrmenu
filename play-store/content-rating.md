# استبيان تصنيف المحتوى (IARC) — تطبيق السائقين

كلا النكهتين (منيورا/تاج) لهما نفس التصنيف — نفس التطبيق، محتوى مطابق.

| السؤال (IARC) | الإجابة |
|---|---|
| Violence (عنف) | None |
| Blood (دماء) | None |
| Sexuality (جنسى) | None |
| Nudity (عُرى) | None |
| Profanity / crude humor (ألفاظ نابية) | None |
| Controlled substances (مخدرات/كحول/تبغ) | None |
| Gambling (مقامرة، محاكاة أو حقيقية) | None — التطبيق لا يحتوى أى مقامرة أو رهان |
| User-generated content shared with others | لا محتوى نصّى حرّ يشاركه السائق مع مستخدمين آخرين (فقط بيانات تشغيلية: موقع، اسم، ملاحظة رفض طلب مُختارة من قائمة أسباب ثابتة) |
| Location sharing | **نعم** — التطبيق يشارك مسار رحلة التوصيل مع المطعم صاحب الطلب، فقط أثناء التوفّر |
| Personal info shared with third parties | نعم، مع المطعم والعميل صاحبَى الطلب فقط (انظر `data-safety.md`) — لا طرف إعلانى |
| Digital purchases / in-app purchases | لا — التطبيق مجانى بالكامل، لا مشتريات داخلية |
| Unrestricted internet access | نعم (اتصال بالباك اند عبر HTTPS فقط) |

**النتيجة المتوقعة:** تصنيف عام لكل الفئات العمرية من ناحية المحتوى (3+ / PEGI 3 وما يعادلها)، لكن انظر `target-audience.md` — **رغم تصنيف المحتوى، الجمهور المستهدف يجب أن يُحدَّد 18+** لأن التطبيق أداة عمل تجارية لسائقين بالغين متعاقدين.
